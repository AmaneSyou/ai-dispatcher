# AI ディスパッチャー

Windows 上で動くローカルのタスク振り分けツールです。プログラミングの作業を 3 つの AI に分担させ、費用を抑えながらサブスクリプションの利用枠を有効に使います。

- **DSH**（DeepSeek Harness）— 安価な従量課金。簡単で繰り返しの多い作業を担当
- **Claude**（Claude Code）— 複雑なコード、デバッグ、コードレビュー
- **Codex** — 設計、難しい問題、大きなタスクの分割

各タスクは独立した git ワークツリーで実行されます。結果は自動でチェックされ、別の AI によるレビューも可能で、プロジェクトに取り込むかどうかは最終的に**あなた**が決めます。

## 主な機能

- **自動振り分け** — AI がコードをざっと読んで難易度を判定し、こなせる中で一番安い AI に割り当てます。
- **自動エスカレーション** — チェックを通らなければ次の AI へ（既定は DSH → Claude → Codex → あなた）。引き継ぎメモと前の AI の報告も渡します。
- **受け入れチェック** — 変更範囲、保護ファイル、変更量、不審な変更のスキャン、そしてプロジェクト独自のコマンド（テスト、lint、ビルド）。
- **相互レビュー** — チェック通過後、別の AI が差分をレビュー。重要な問題があれば差し戻して修正させます。
- **大きなタスクの分割** — Codex が依存関係つきの小タスク案を作成し、あなたが編集・承認。依存するタスクは前のタスクがマージされるまで待ちます。
- **ワンクリックのマージ／取り消し** — 先に一時コピー上でマージして再チェックし、未コミットの作業は上書きしません。取り消しは revert コミットで行います。
- **パッチ出力／自分のリポジトリへ push** — 変更を `git am` 用パッチとして取り出すか、新しいブランチ `dispatcher/task-番号` に push できます。
- **利用枠の保護** — Claude／Codex の 5 時間枠・週枠の残りが、自分用に残す割合まで減ったら振り分けを止めます。日次上限つきの有料モードも任意で使えます。
- **リアルタイム安全監査** — すべてのツール呼び出しを確認し、作業ツリー外への書き込み、認証情報の読み取り、`git push`、権限昇格などを検知すると即座に停止します。
- **GUI** — ローカルの Web パネル（Edge のアプリウィンドウで表示）、トレイアイコン、Windows 通知、背景画像と透明度の設定、チュートリアルと FAQ を収めた**ヘルプ**ページ。

## 必要なもの

| 必須 | 説明 |
|---|---|
| Windows 10 / 11 | トレイ、通知、パネル画面は Windows 前提です |
| [Node.js](https://nodejs.org/) 24 以上 | TypeScript を直接実行します（`npm install` 不要） |
| [Git for Windows](https://git-scm.com/download/win) | タスクごとに git ワークツリーを使います |
| DeepSeek Harness デスクトップ版 + DeepSeek API キー | 安価なメインの作業役 |

任意：Claude Code（Claude のサブスクリプション）、Codex（ChatGPT のサブスクリプション）。プロジェクトで必要なら pnpm／Rust／Python も（`安装工具.ps1` でプログラムのフォルダー内にインストール。システム設定は変更しません）。

## はじめ方

1. アーカイブを固定の場所に展開します（例：`D:\AI-Dispatcher`）。
2. **`首次安装.cmd`**（初回セットアップ）をダブルクリック：Node と Git を確認し、設定ファイルを作成して、デスクトップに「AI 调度器」のショートカットを作ります。作業フォルダーは同じドライブの `AgentWork` が既定です。
3. DeepSeek の API キーだけを `<作業フォルダー>\secrets\deepseek.key` に保存します。
4. 任意：**`安装工具.ps1`** を右クリック →「PowerShell で実行」で pnpm／Rust／Python をインストール（公式配布元から取得し、チェックサムを照合）。
5. デスクトップのショートカットを開き、**环境检查**（環境チェック）で **开始检查** をクリック。すべてチェックが付いたら **设置 → 项目 → 创建演示项目**（デモプロジェクト作成）でタスクを試してみてください。

画面は現在、簡体字中国語のみです。**帮助**（ヘルプ）タブで各画面の説明と、複雑なタスクの流れを一通り確認できます。

## 安全上の注意

- AI はそれぞれのサンドボックス内で動き、リアルタイムに監査されますが、**受け入れチェックのコマンドはサンドボックスの外であなたの権限で実行されます**（AI が変更したコードを実行するため）。信頼できるプロジェクトだけを登録し、難しいタスクはなるべく在席時に実行してください。
- チェック時に実行されるビルド設定（`build.rs`、`.cargo`、`.npmrc`、`package.json`、`vite.config.*` など）は保護しておくべきです。主なものは既定で保護されています。
- パネルは `127.0.0.1` だけで待ち受け、起動のたびに新しいランダムなトークンを使います。
- API キーは `secrets` フォルダーにだけ置き、プロジェクトのコードやタスクの説明には書かないでください。
