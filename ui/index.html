第一次用？先看 ，或者到“设置 → 项目”点“创建演示项目”试一个任务。想了解一次复杂任务从立项到验收怎么走，看 。

新建任务

写得越具体，便宜的 AI 越容易一次做对。任务会在独立的副本里完成，不会直接改动你的项目，最后由你决定是否接受。

还没有登记项目。可以先到“设置 → 项目”里添加，或者 试试。

子代理 每家单独设置，只在这家处理这个任务时生效（例如 DSH 失败升级给 Claude，用的是 Claude 的设置）。量大但简单的活适合开 DSH；Claude / Codex 的子代理很费额度
大任务

适合大任务：先让一个 AI 读代码、列出小任务清单，你看过（可以改）并批准后才开始做。勾选后，上面的“交给谁”和子代理设置都是给小任务用的。

不勾就要你逐个点“合并到项目”。有先后关系的小任务，要等前一项合并后才开始。自动合并同样先复检，可以撤销。

Claude 每 5 分钟自动刷新一次；手动刷新同样不消耗额度。

Claude 的额度来自最近一次 Claude 运行；Codex 的额度来自 Codex 的会话记录（包含你在 Codex App 里的使用）。剩余额度降到“设置 → 额度保护”里为你保留的比例时，调度器就不再自动派任务给它，剩下的留给你自己用。

环境检查

检查程序、登录状态、权限和安全补丁。只看状态，不调用模型，不花钱。
